# 我們家的旅行

家庭共用的旅遊行程規劃工具。電腦上蒐集和編輯，旅途中用手機查看與微調，沒網路也能打開。

- 網站放在 GitHub Pages（免費）
- 資料放在 Firebase Firestore 免費方案（不用綁信用卡）
- 不用安裝、不用建置：所有檔案原封不動放上 GitHub 就能用

## 目前功能

**第一階段**
- 邀請連結登入：第一次點連結加入，之後免登入；沒有連結的人看不到資料
- 旅行列表：即將出發、過去的旅行、搜尋；每趟旅行可上傳封面圖（自動壓縮）
- 行程看板：每天一欄往右排，卡片可拖曳排序、跨天移動，還有「待排」欄
- 卡片：類型、時間、狀態（已訂／備案／取消）、地點（連結或地址都能開 Google Maps）、連結、訂位資訊、備註
- 手機「今天」：時間軸、左右滑換天、卡片收合展開、依類型篩選
- 加到主畫面、離線使用、新版本自動套用

**第二階段**
- 區塊：待辦、航班、票券、清單、每日穿搭、花費、參考連結；可拖曳排序、隱藏、重新命名；可新增「筆記」「附件」區塊
- 航班：登機證樣式，可附機票截圖或 PDF
- 票券：可附 PDF 電子票（保留原檔），「出示票券」直接打開；有網路時會先下載，離線也能打開
- 清單：行李、採購可分人；伴手禮可指定送給誰，依對象或依品項查看
- 每日穿搭：依人編輯、依日期查看、總表；手機「今天」最上方顯示全家當天穿搭
- 花費：依旅遊國家預設當地貨幣，可改台幣；自動抓參考匯率換算台幣；卡片上填的花費會自動記進來
- 卡片可加圖片（自動壓縮）
- 設定：家庭成員、送禮對象（全家共用，每趟沿用）
- 手機分頁：今天、票券、清單、花費、更多

## 先試用（示範模式）

`js/config.js` 還沒填 Firebase 設定時，App 會以示範模式執行，資料只存在那台裝置的瀏覽器，用來先試操作。

在電腦上試：在這個資料夾打開終端機，執行

```bash
python3 -m http.server 5178
```

再用瀏覽器開 http://localhost:5178

## 設定 Firebase（約 10 分鐘，只做一次）

1. 到 https://console.firebase.google.com 用 Google 帳號登入，按「建立專案」。名稱隨意，Google Analytics 可以關掉。
2. **開啟匿名登入**：左側「建構 → Authentication」→「開始使用」→「登入方式」→ 選「匿名」→ 啟用 → 儲存。
3. **建立資料庫**：左側「建構 → Firestore Database」→「建立資料庫」→ 位置選 `asia-east1 (台灣)` →「以正式版模式啟動」。
4. **貼上安全規則**：Firestore 的「規則」分頁，把這個資料夾裡 `firestore.rules` 的全部內容貼上，按「發布」。
5. **取得設定**：左上齒輪「專案設定」→「一般」→ 最下面「你的應用程式」→ 按網頁圖示 `</>` → 隨意取名 → 註冊。畫面會出現一段 `firebaseConfig = { ... }`，把裡面的值填進 `js/config.js`。
6. **建立第一個邀請碼**（因為一開始還沒有任何成員，第一個要手動建）：
   - Firestore 的「資料」分頁 →「開始集合」→ 集合 ID 填 `invites`
   - 文件 ID：填一串很長、別人猜不到的英數字（至少 24 個字）
   - 新增欄位 `active`，類型「boolean」，值 `true`
   - 儲存
7. 網站上線後（見下一段），用這個網址加入：
   `https://你的帳號.github.io/儲存庫名稱/#/join/剛剛的文件ID`
   加入後，到 App 的「設定 → 邀請家人」產生連結給家人，不用再進 Firebase。

## 放上 GitHub Pages

1. 在 GitHub 建一個 **Public** 儲存庫（免費帳號的 Pages 需要公開儲存庫；裡面只有程式碼，行程資料在 Firebase）。
2. 把這個資料夾的所有檔案推上去（包含 `.nojekyll`）。
3. 儲存庫「Settings → Pages」→ Source 選「Deploy from a branch」→ Branch 選 `main`、資料夾 `/ (root)` → Save。
4. 一兩分鐘後網址就會出現在同一頁。

## 更新程式之後

修改任何檔案後，把 `sw.js` 第一行附近的 `VERSION` 加 1（例如 `v1` → `v2`），家人手機上的 App 才會換成新版。打開 App（或從背景切回 App）時會自動檢查新版本，下載好後自動重新載入一次；如果當下正在編輯卡片，會等關掉編輯視窗再更新。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 入口 |
| `js/app.js` | 畫面與操作 |
| `js/store-firebase.js` | Firebase 資料存取（含離線快取） |
| `js/store-demo.js` | 示範模式的資料存取與範例資料 |
| `js/config.js` | Firebase 設定 |
| `js/utils.js` | 共用小工具 |
| `js/vendor/` | Preact + htm（畫面）、SortableJS（拖曳） |
| `css/app.css` | 樣式 |
| `sw.js`、`manifest.webmanifest` | 離線與加到主畫面 |
| `firestore.rules` | 資料庫安全規則 |

## iPhone 加到主畫面

iPhone 的主畫面 App 和 Safari 資料是分開的，所以要加入兩次：
1. 用 Safari 打開網站 → 分享 → 加入主畫面
2. 從主畫面打開 App，在 LINE 長按邀請連結 → 拷貝，貼到歡迎畫面的欄位 → 加入

## 管理裝置

「設定 → 已加入的裝置」可以看到誰加入了、移除遺失的手機。「邀請家人」裡的連結可以隨時停用。清除瀏覽器資料或換手機時，再點一次邀請連結即可。
